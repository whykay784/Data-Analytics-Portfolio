# AdventureWorks Regional Sales Analysis Dashboard

## 📌 Project Overview

This project involves analyzing sales performance across different regions of AdventureWorks, a global manufacturing company. Using Power BI, I developed an interactive dashboard to evaluate business performance, monitor key sales metrics, identify product trends, and understand customer purchasing behaviour.

The dashboard provides insights into revenue generation, profitability, order volumes, product performance, and regional sales distribution to support data-driven business decisions.

## 📊 Key Insights & Metrics

- **Total Revenue:** Generated $2.49M in total revenue.
- **Total Profit:** Recorded a net loss of ($11.97M), highlighting the need to investigate operational costs, product returns, and pricing strategies.
- **Total Orders:** Recorded 25.16K orders.
- **Return Rate:** Maintained an overall return rate of 2.17%.
- **Top Product Category:** Components recorded the highest order volume, followed by Accessories and Clothing.
- **Top Performing Product:** Sport-100 Helmet (Red) generated over $7,300 in sales.
- **Popular Product Type:** Bottom Brackets recorded the highest individual product-type order volume.

## 🛠️ Tools & Technologies

- **Power BI Desktop:** Dashboard development and data visualization.
- **Power Query:** Data cleaning and transformation.
- **DAX (Data Analysis Expressions):** Created calculated measures and KPIs for revenue, profit, order trends, and return-rate analysis.
- **Data Modelling:** Established relationships between relevant tables to support interactive analysis.
- **Data Visualization:** Used cards, charts, maps, gauges, and slicers to communicate business insights.
