# 📊 SQL Portfolio Analytics

## Overview
# 🏥  Healthcare Analytics

This repository contains SQL analytics projects completed using Google BigQuery Public Datasets. The projects demonstrate advanced SQL querying, business intelligence reporting, and data-driven decision making across Healthcare industry.

## Problem Statement

Healthcare providers charge significantly different prices for similar procedures, creating pricing inconsistencies across regions.

## Objectives

* Compare provider charges
* Detect pricing outliers
* Analyze regional healthcare costs

## Methodology

Cost aggregation, ranking functions, statistical comparison, and geographic analysis.

## SQL Skills Used

* SUM()
* AVG()
* RANK()
* CASE
* Window Functions

## Results

* Significant cost variation exists across providers.
* Pricing outliers were successfully identified.

## Business Insight

Healthcare organizations can improve transparency and reduce pricing inconsistencies through data-driven monitoring.
